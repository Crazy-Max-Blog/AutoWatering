# АвтоПолив64
### Описание
Данная система решает проблему отсутствия возможности полить растение, что является жизненно важным для них. Наш проект рассчитан на комнатные растения, но его легко приспособить под уличные, если заменить исполнительные механизмы.
### Требования и технологии
При разработке данной системы мы использовали программы *Visual Studio Code* и *Компас 3D* и оборудование: *3D-принтер* и *Компьютер*

Также мы использовали следующие технологии:
- Wi-Fi
- MQTT
- Web-интерфейс
- Интеграция с Telegram и умным домом
### Настройка
При включении устройства создаётся точка доступа *AutoWatering*, при подключении к которой автоматически открывается полный web-интерфейс. В пункте *настройки* необходимо указать логин и пароль Wi-Fi
